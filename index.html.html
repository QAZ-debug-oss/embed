    打不开 / 提示"会话已过期"怎么办

    原因：这份文件是 html，用"云盘预览 / 聊天里直接点开"的方式打开时，iOS 走的是带临时链接的预览会话，链接几分钟就失效，所以一会就报"会话已过期"。文件本身没坏，也没有联网依赖。

    根治方法（把文件真正存到手机本地）：
    ① 用「文件」App 打开 -> 长按这个 html -> 选择「拷贝」；
    ② 进入 「我的 iPhone」（不是 iCloud 云盘）-> 新建文件夹如 嵌入式 -> 「粘贴」；
    ③ 从「我的 iPhone」里点开它 -> 会交给 Safari 渲染（不再经过云盘预览）；
    ④ Safari 底部分享 -> 添加到主屏幕，以后从图标进，全屏、离线可用。

    电脑上：直接双击本地文件用 Chrome/Edge 打开即可，别把云盘同步目录里的文件一直放在"预览"状态。
    文件名：若某些 App 打不开中文名文件，先改成 index.html 或 embed.html 再试。

    想更省事的方案

    把 嵌入式打卡.html 传到 GitHub Pages（免费）得到一个网址，iPhone 用 Safari 打开该网址再"添加到主屏幕"。这样它是一个真正的在线地址，不会出现本地预览过期的问题，也能同步给同学一起用。
