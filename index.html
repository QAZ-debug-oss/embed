    使用说明

    1. 每周打开 App，勾掉做完的任务与检验项；
    2. 状态选 ✅ 通过 / ⚠️ 及格（记欠账）/ ❌ 不通过（用机动周补）；
    3. 填本周实际投入小时数，写三行复盘；
    4. 每 4 周结束去「周测」做整章测评并记录分数；
    5. 数据只存在这台设备里，换设备前用下面「导出备份」。

    打不开 / 提示「会话已过期」？

    原因：这是 iOS 打开云盘/聊天里文件的临时预览会话到期所致，文件本身没坏、也不需要联网。
    解决：「文件」App 长按本文件 → 拷贝 → 进 「我的 iPhone」（不是 iCloud 云盘）→ 粘贴 → 从那里点开 → Safari 分享 → 添加到主屏幕。
    更省事：传到 GitHub Pages 得到网址，Safari 打开后添加到主屏幕，永不过期。
